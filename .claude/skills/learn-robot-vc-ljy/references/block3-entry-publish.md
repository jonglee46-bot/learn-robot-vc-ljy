# Block 3: 부품사의 진입 기회와 공개

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://jonglee46-bot.github.io/learn-robot-vc-ljy/
> ```

## EXPLAIN

### 1. 진입을 판단하는 용어

| 용어 | 뜻 |
|---|---|
| 파일럿 | 실제 현장에서 정해진 기간 동안 작업을 시험하는 도입 전 단계 |
| KPI | 파일럿의 성과를 판단하는 측정 지표 |
| 확대 조건 | 파일럿을 정식 도입으로 넓히기 위해 충족해야 할 조건 |
| 진입 경로 | 어떤 제품과 고객으로 시장에 들어갈지 정한 방법 |

Counterpoint는 2027년 휴머노이드 설치의 72%를 물류, 제조, 자동차가 차지할 것으로 전망한다[S13]. 그중 자동차는 24%다[S13].

### 2. 왜 경로를 비교하는가

| 경로 | 사례 | 공개된 계획 | 특징 |
|---|---|---|---|
| 액추에이터 모듈 공급 | 현대모비스 | 2028년 공급 예상 [S23], 2028년 미국 연산 35만 대 계획 [S24] | 그룹 내 수요가 있어 첫 고객 후보가 분명하다 |
| 액추에이터 신규 진출 | HL만도 | 2028년 북미 양산 [S29], 2035년 점유율 10% 목표 [S30] | 외부 고객을 확보해야 한다 |
| 핵심 부품 전문 | 에스피지 | 감속기 사업 확대 [S20] | 작은 매출에서 시작해 고객 사례를 쌓는다 |

### 3. 케이스: HL만도는 자동차 제어 역량을 관절로 옮긴다

HL만도는 자동차 제어 시스템 사업에서 쌓은 내구성과 품질을 로봇 액추에이터의 강점으로 내세운다[S19]. 같은 보고서는 아직 휴머노이드 수주가 없다는 점도 함께 짚었다[S19]. 역량은 맞아 보여도 수주가 나오기 전까지는 가설이다.

### 4. 공개 전 수칙

사내 자료는 공개 저장소에 올리지 말고 사내 문서로만 작성한다. 내 회사 역량 점검표도 마찬가지다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
내 회사 역량 점검표를 만들어 주고 공개 상태를 확인해 줘. 새 저장소는 만들지 말고, 아무것도 올리지 마.
1. robot-vc-lab/outputs/my_company_check.md 에 아래 6개 항목의 빈 표를 만들어 줘. 칸은 점검 항목, 우리 회사의 답, 근거 자료다.
   로봇에 바로 쓸 수 있는 제품 또는 기술 / 들어갈 계층과 부품 / 첫 고객 후보와 접점 / 시험해 볼 현장 / 부족한 역량과 보완 방법 / 확인이 필요한 고객 요구 사양
2. 이 파일은 사내 문서로만 쓴다고 맨 위에 적어 줘.
3. 대시보드 주소 https://jonglee46-bot.github.io/learn-robot-vc-ljy/ 가 열리는지 확인해 줘.
4. 아래 설치 한 줄을 그대로 보여 줘.
   npx skills add jonglee46-bot/learn-robot-vc-ljy --agent claude-code --global --yes
```

### 확인할 것 (Phase B)

- `robot-vc-lab/outputs/my_company_check.md`에 항목 6개가 있다.
- 파일 맨 위에 사내 문서라는 안내가 있다.
- 대시보드 주소가 응답한다.

주소가 안 열리면 "대시보드 주소가 안 열려. Pages 상태를 확인해 줘"를 붙여 넣게 한다. 확인과 퀴즈가 끝나면 대시보드 주소를 다시 보여 주고 "수업 끝"을 출력한다.

## QUIZ

```json
AskUserQuestion({
  "questions": [{
    "question": "수주가 없는 부품사가 로봇 부품 신뢰성 자료를 준비한다. 고객사 요구 사양은 미확보이고, 공개 사례표에는 파일럿에서 전완부가 주요 고장 부위였다고 정리되어 있다[S34]. 어떻게 시작해야 하는가?",
    "header": "Quiz 1",
    "options": [
      {"label": "수주 후에 시험한다", "description": "고객이 정해지기 전에는 준비하지 않는다"},
      {"label": "자동차 기준 통과를 제시한다", "description": "기존 시험 결과를 로봇에도 그대로 쓴다"},
      {"label": "사례로 좁히고 고객 기준을 확인한다", "description": "작업과 고장 부위로 시험 범위를 좁히고 표본과 자료를 준비한다"}
    ],
    "multiSelect": false
  }]
})
```

정답: 3번. 고객사의 시험에 들어갈 표본과 신뢰성 자료를 먼저 갖추는 일이 우선 과제가 될 수 있다. 수주를 기다리면 역량은 끝까지 가설로 남는다. 자동차 기준 통과만으로는 로봇 고객의 요구 사양을 알 수 없다. 현장에서는 파일럿의 작업과 고장 부위로 범위를 좁히고, 어느 고객 기준으로 시험할지 확인한다.
