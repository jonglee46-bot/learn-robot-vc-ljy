## EXPLAIN

### 1. 원가를 읽는 용어

| 용어 | 뜻 |
|---|---|
| BOM | 로봇 한 대에 들어가는 부품과 원가의 목록 |
| 액추에이터 | 전기 신호를 움직임으로 바꾸는 구동 장치. 로봇 관절의 근육이다 |
| 감속기 | 모터의 빠른 회전을 늦추는 대신 힘을 키우는 기어 장치 |
| 병목 | 수요가 늘 때 물량, 품질, 가격이 따라가지 못해 전체 생산을 막는 지점 |

### 2. 왜 비중을 하나로 단정하지 않는가

| 값 | 기준 | 출처 |
|---|---|---|
| 약 60% | 휴머노이드 재료비 | [S17] |
| 약 60% | 휴머노이드 제작 원가 | [S18] |
| 44% | 제조 원가 추정 | [S19] |
| 50% 초과 | BOM, 2030년 전망 | [S13] |

재료비와 제조 원가는 범위가 다르고, 액추에이터에 무엇을 넣느냐에 따라서도 값이 달라진다. 교재에서는 '절반 안팎'이라는 방향만 읽는다.

BofA는 액추에이터, 센서, 감속기, 배터리 같은 부품이 대규모 생산에 필요한 물량, 신뢰성, 원가 구조를 아직 갖추지 못했다고 본다[S13]. 실제 납품 단가와 구체적인 신뢰성 기준은 공개 자료로 확인하지 못했다(미확보).

### 3. 케이스: 에스피지는 본업 위에 감속기를 얹었다

에스피지는 기존 본업을 유지하면서 감속기로 로봇 부품 사업을 넓히고 있다[S21]. 2025년 연간 매출은 3417억원이었다[S21]. 그중 로봇·정밀 감속기 비중은 3~4%로 분석되며[S20], 3%로 보도한 기사도 있다[S21].

### 확인할 것 (Phase B)

- `robot-vc-lab/outputs/bom_chart.html`이 있고 막대가 4개다.
- 값이 131,000, 46,000, 35,000, below 17,000(17,000달러 미만)이다.
- 직접 비교하지 않는다는 문장이 있다.

정답: 2번. BOM은 로봇 한 대의 추정 원가이지 납품 단가가 아니며, 어떤 로봇과 기준으로 추정했는지부터 봐야 한다. 공개 값을 단가로 간주하면 미확보 자료를 사실처럼 쓰게 된다. 131,000달러는 중국 공급망을 빼는 가상 시나리오의 값이라 기준으로 삼을 수 없다[S15]. 현장에서는 BOM이 내려가는 시장에서 자사 원가 구조가 버틸 수 있는지를 먼저 점검한다.
