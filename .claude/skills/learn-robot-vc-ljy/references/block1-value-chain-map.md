## EXPLAIN

### 1. 세 계층과 두뇌층

| 계층 | 하는 일 | 부품사가 볼 점 |
|---|---|---|
| 두뇌층 | 인식, 판단, 동작 제어 | 직접 경쟁보다 연동 요구 사항을 파악한다 |
| 부품 | 액추에이터, 감속기, 센서, 배터리 공급 | 자동차 부품 역량이 가장 직접 이어진다 |
| 본체 | 로봇 설계와 조립 | 부품사의 고객이 모인다 |
| 응용 | 공장과 물류 현장의 실제 작업 | 신뢰성 요구가 드러나는 곳이다 |

로봇은 산업용 로봇, 협동 로봇, AMR, 휴머노이드의 네 갈래로 나뉜다[S22].

### 2. 왜 지도부터 그리는가

| 기준 | 기사부터 읽기 | 지도부터 그리기 |
|---|---|---|
| 판단 대상 | 어느 계층의 이야기인지 놓치기 쉽다 | 자사가 닿을 수 있는 계층을 먼저 정한다 |
| 숫자 | 눈에 띄는 값부터 본다 | 무엇을 세었는지 먼저 본다 |

세계 산업용 로봇 설치는 2024년 542,076대였다[S01]. 2025년에는 600,000대를 넘었고 전년보다 11% 늘었다[S03]. 휴머노이드는 아직 초기 시장이고 수량부터 기관마다 다르다.

### 3. 케이스: 현대차그룹은 계층을 그룹 안에서 잇는다

현대모비스가 액추에이터를 맡고, Boston Dynamics가 Atlas 본체를 만들며, 그룹의 공장이 응용 현장이 된다[S26]. 보도에 따르면 그룹은 2028년까지 미국에서 연 30,000대를 생산하는 체계를 만들 계획이다[S26][S27]. 현대차와 기아 사업장에는 Atlas를 25,000대 이상 배치할 계획이라고 보도됐다[S28]. 실제 물량과 계약 금액은 공개 자료로 확인하지 못했다(미확보).

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
robot-vc-lab/data/facts.csv 로 휴머노이드 수량 표를 만들어 줘. 원본은 고치지 마.
1. 번호 F13, F14, F15 행과 F13 비고의 값을 읽어 기관, 수량, 집계 대상, 출처를 정리해 줘.
2. IFR은 F13의 값과 비고의 값을 두 행으로 나눠 모두 4행으로 만들어 줘.
3. 평균을 내거나 값을 하나로 고르지 마.
4. robot-vc-lab/outputs/humanoid_count.csv 로 저장하고 표로 보여 줘.
```

### 확인할 것 (Phase B)

- `robot-vc-lab/outputs/humanoid_count.csv`가 있고 데이터가 4행이다.
- IFR 값 Almost 6,900와 Nearly 7,000가 함께 있다.
- Counterpoint 16,000과 BofA 20,000이 집계 대상과 함께 있다.

막히면 "방금 결과가 프롬프트와 다른 곳을 찾아 고쳐 줘"를 붙여 넣게 한다. 정답은 "정답 보기" 요청이 있을 때만 연다.
