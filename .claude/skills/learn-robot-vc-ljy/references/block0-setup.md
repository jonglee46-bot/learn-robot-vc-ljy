## EXPLAIN

### 1. 이 강의의 자료

| 자료 | 뜻 |
|---|---|
| 교재 | 로봇 밸류체인, 원가와 병목, 부품사의 진입 기회를 다룬 세 장 |
| 강의 덱 | 교재를 슬라이드로 옮긴 자료 |
| sources.md | 출처 34개의 표. 문장 끝의 [S01] 같은 번호가 여기로 이어진다 |
| facts.csv | 교재에 쓸 숫자 후보 44개와 교차 확인 상태 |

이 강의가 답할 핵심 질문은 하나다. 자동차 부품사는 로봇 밸류체인의 어느 단계에서 자사의 기술과 공급 역량으로 새 사업 기회를 만들 수 있는가?

### 2. 왜 숫자의 상태부터 보는가

| 상태 | 개수 | 쓰는 법 |
|---|---|---|
| 교차확인 | 29 | 본문에 쓴다 |
| 출처 간 불일치 | 7 | 출처별로 병기하고 하나로 단정하지 않는다 |
| 보류 | 8 | 교재에 쓰지 않는다 |

로봇 시장은 추정치가 많고 기업 소식이 빠르게 바뀐다. 기사 하나로 사업 기회를 판단하면 어느 계층의 이야기인지 놓치기 쉽다.

### 3. 공개 자료의 한계

실제 납품 단가와 고객사의 요구 사양은 공개 자료로 확인하지 못했다(미확보). 그래서 이 강의는 공개 사례로 판단 기준을 세우고, 자사 역량은 수강생이 직접 적는 틀로 둔다. 기업 사례는 학습용이며 투자 권유가 아니다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. `{SKILL_DIR}`는 Phase A 출력 직전에 이 스킬 폴더의 실제 경로로 바꿔 보여 준다.

```
수업 실습을 준비해 줘.
1. 지금 폴더 아래 robot-vc-lab/data 와 robot-vc-lab/outputs 폴더를 만들어 줘.
2. {SKILL_DIR}/assets/lab/facts.csv 와 sources.md 를 robot-vc-lab/data 로 복사해 줘. 원본은 고치지 마.
3. facts.csv 의 전체 숫자 개수와 상태별 개수, sources.md 의 출처 개수를 세어 줘.
4. 결과를 robot-vc-lab/env_check.txt 에 저장하고 한 줄로 알려 줘.
```

### 확인할 것 (Phase B)

- `robot-vc-lab/data/facts.csv`의 숫자가 44개이고 상태별로 교차확인 29, 출처 간 불일치 7, 보류 8개다.
- `robot-vc-lab/data/sources.md`의 출처가 34개다.
- `robot-vc-lab/env_check.txt`가 있다.

막히면 "방금 오류의 원인과 해결을 한 줄씩 설명한 뒤 고쳐 줘"를 붙여 넣게 한다. 정답은 "정답 보기" 요청이 있을 때만 연다.

      {"label": "집계 대상을 밝혀 병기한다", "description": "무엇을 세었는지 적고 계획에 쓸 조건을 정한다"}

  }]

```

정답: 3번. 세 값은 판매, 설치, 출하로 집계 대상이 달라 값을 하나로 고르지 않고 함께 적는다. 평균은 서로 다른 것을 섞는 일이고, 가장 큰 값을 고르면 근거 없이 낙관하게 된다. 숫자가 어긋날 때는 무엇을 세었는지부터 확인해야 한다.
